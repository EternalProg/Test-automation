# Лабораторна робота № 3

## Практикум із розроблення через тестування

**Варіант:** 1 — тарифікатор доставки.  
**Виконавець:** [[CHANGE: ПІБ та група]]

Проєкт містить показовий модуль тарифікації паркування та індивідуальний
тарифікатор доставки. Зміни реалізовано послідовними кроками Red–Green–Refactor,
кожен тестовий і програмний крок зафіксовано окремим комітом.

## Встановлення та перевірка

```bash
npm install
npm test
npm run coverage
npm run lint
npx tsc --noEmit
npm run format:check
```

HTML-звіт покриття створюється у `coverage/index.html`.

## Структура

- `src/parking.ts` — тарифікатор паркування з нічним і вихідним тарифами.
- `src/delivery.ts` — тарифікатор доставки, варіант 1.
- `tests/parking.test.ts` — модульні тести показового прикладу.
- `tests/delivery.test.ts` — модульні тести індивідуального варіанта.
- `vitest.config.ts` — запуск тестів та пороги покриття.
- `tsconfig.json` — сувора перевірка типів TypeScript.
- `eslint.config.mjs`, `.prettierrc` — статичний аналіз і форматування.

Звіт і матеріали для виступу зберігаються локально в `report/` та не входять
до Git. Робоча гілка — `lab3`.
