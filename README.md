# Лабораторна робота № 4

## Тестові дублери та перехоплення мережевих запитів

**Варіант:** 1 — сервіс скасування замовлення з поверненням коштів через HTTP
і надсиланням листа після успішної операції.

**Виконавець:** [[CHANGE: ПІБ та група]]

## Встановлення та запуск

```bash
npm install
npm test
npm run coverage
npm run lint
npx tsc --noEmit
npm run format:check
```

HTML-звіт покриття створюється у `coverage/index.html`.

## Структура

- `src/order-service.ts` — показовий сервіс оформлення замовлення.
- `src/retry.ts` — повторення асинхронної операції з контрольованою затримкою.
- `src/rate-provider.ts` — HTTP-провайдер курсу валют.
- `src/payment-gateway.ts` — HTTP-адаптер повернення коштів.
- `src/cancellation-service.ts` — бізнес-логіка скасування замовлення.
- `tests/fakes/` — підробки сховища та платіжного шлюзу зі станом.
- `tests/msw/server.ts`, `tests/setup.ts` — налаштування перехоплення HTTP.
- `tests/*.test.ts` — тести сервісів, таймерів і HTTP-сценаріїв.
- `vitest.config.ts` — конфігурація Vitest, setup та покриття.
- `report/` — локальний DOCX-звіт і матеріал доповіді; каталог ігнорується Git.

Проєкт використовує MSW із `onUnhandledRequest: 'error'`, тому тести не
виконують незаданих реальних мережевих запитів.
